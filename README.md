### 2. Spam Email Detection

A machine learning project that classifies emails as spam or not spam using
TF-IDF feature extraction and a Multinomial Naive Bayes classifier.

#### Interactive Spam Email Dashboard

The spam detection project includes an interactive Streamlit dashboard that
allows users to analyze an email or message without using the command line.

The dashboard provides:

- Spam / Not Spam prediction
- Model confidence
- Spam and Not Spam probabilities
- Risk level classification
- Risk score and risk signals
- Suspicious terms detection
- Explanation of suspicious patterns
- Message statistics such as characters, words and links
- Dynamic safety recommendations

The dashboard combines the machine learning prediction with a transparent,
rule-based risk analysis layer to make the results easier to understand.
